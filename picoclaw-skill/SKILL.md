# astro-dice 占星骰子

掷出三颗骰子（行星 · 星座 · 宫位），按「一条河」流水十二程体系输出完整解读。

## 使用方法

```bash
node scripts/roll.js [想问的问题]
```

- 不带参数直接掷骰；带参数时把问题写进解读（问题可含空格，不需要引号）。
- 脚本的输出即完整解读，**原样呈现**给用户，不要改写、补掷或自行另解。

## 解读体系（一条河）

- **行星 = 水性**：这是什么样的水（凝聚、静水、内流、完美、冲动、惯性、静止、冲击、漫延、高压……）。
- **星座 = 流法**：水怎样流、行至第几程（涌出、聚潭、分流、归根、汇聚、内流、平流、潜渊、瀑布、水潭、入海、海浪）。
- **宫位 = 归处**：水归于何处、又至第几程（1宫流出之地 … 12宫浪潮无尽）。
- 程数即阶段：1–4 泉源期、5–8 江河期、9–12 归海期。星座程数与宫位程数两相对照，分别描述「行事方式所处的阶段」与「事情落点所处的阶段」。

详细对照表、断语规则见 `references/river-method.md`；骰面文本与具体断语全部在 `assets/rules.json`，可直接替换为自定义解读法（JSON 不支持注释）。
